# 图床测试文档

这是一份用于测试图床图片是否能够正常加载并展示的 Markdown 文件。

## 1. 直接引用图床相对路径

如果后端上传后返回的是类似下面这样的路径，请确认前端能够正常解析并显示：

![测试图片 1](/static/upload/test/demo-1.jpg)

## 2. 直接引用完整 URL

如果后端返回的是完整地址，也应该能够正常显示：

![测试图片 2](http://localhost:8080/static/upload/test/demo-2.jpg)

## 3. 混合文字与图片

下面这张图如果能正常显示，说明图片地址、静态资源和 Markdown 渲染都没有问题。

![测试图片 3](/static/upload/test/demo-3.png)

### 说明

- 如果你看到图片无法显示，先检查返回的地址是否以 `/static/upload` 开头。
- 如果是相对路径，前端会自动拼接 API 基础地址。
- 如果是完整 URL，前端会直接使用。

> 只要这份 Markdown 里的图片能正常显示，就说明图床展示链路基本没问题。
